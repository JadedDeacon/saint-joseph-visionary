# Versioning and Backup Policy

- Current version: v1 (main branch)
- Backup branches are created every 10 significant updates (e.g., backup-v10, backup-v20).
- Each backup branch freezes the state of BOOK.md and related files at that point.
- To restore a prior state, check out the corresponding backup branch or compare commits.
- Full commit history remains available on main for finer-grained recovery.
